# Superseded Mode 4 prototype

The former single-TX receive-scan Mode 4 has been removed from the deployed
GUI and replaced by the two-TX phased-array STT mode. Its internal CLI path is
retained only for recovery and comparison; it is not one of the submission
test modes.

Use [README_TWO_MODE_TEST.md](README_TWO_MODE_TEST.md) for the current setup,
calibration and test procedure.
