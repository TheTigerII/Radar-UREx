Executive Summary of the UREx Extension

[Student Name]   [Student Number]   National University of Singapore   November 2026

Purpose

This work extends the IWR6843ISK-ODS, DCA1000EVM and Jetson Orin Nano prototype to investigate longer sampled range and directional receive sensitivity while preserving the earlier project baselines. It also replaces routine terminal operation with a touchscreen-oriented GUI and tactical top-down display. Final controlled range testing has not yet been completed, so this summary describes implementation and test intent rather than claiming a performance improvement.

  • Added a tactical PPI with range, bearing, trail and estimated relative altitude.
  • Added tracker-driven calibration progress, ready/search/track state and target-attached annotation.

How range is being changed

Mode 2 changes chirp slope and therefore the sampled range mapping; it does not change transmit power or antenna gain. Mode 3 changes effective receive processing gain by coherently combining channels in selected directions. Mode 4 also uses coherent receive weights, but only across four physical receivers. None of the new modes performs validated transmit phase steering or raises EIRP. Lower thresholds and PMM integration change the evidence required for a detection, not the physical received power.

Classification and operating limits

The existing LSTM model is fingerprinted to Mode 1. It is deliberately disabled for Modes 2–4 until labelled mode-specific data are collected and a compatible model is trained. Mode 4 is receive-steered SIMO, not military-style transmit AESA. The present PMM tracker follows one dominant target.

Planned verification

  • Run all four modes from the same position against the same target and marked route.
  • Keep the field clear for the full tracker-reported background calibration.
  • Measure confirmed static/moving range, track coverage, false alarms, range/angle error and distant snap events.
  • Compare packet integrity, processing drops, p95 latency, deadline misses and Jetson resource use.
  • Repeat each condition and include empty-scene controls.

Pre-test conclusion

The original PMM mode remains directly usable and the conventional mode remains recoverable from Git, although it is not deployed in the current GUI. The extension provides three technically different PMM experiments and a more practical field interface. Whether any new mode increases useful drone-detection range must remain open until matched final tests are completed.
